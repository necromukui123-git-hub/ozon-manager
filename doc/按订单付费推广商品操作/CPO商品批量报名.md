# CPO 商品批量报名

本文件只描述 Search CPO 页面里的人工批量报名工具，不包含 `state2 -> enable -> Morkovsk` 的自动迁移逻辑。  
自动迁移规则请看：`doc\按订单付费推广商品操作\推广商品添加活动规则.md`。

## 功能目标
1. 刷新按订单付费推广商品列表。
2. 在本地按关键词、推广状态、规则状态、库存、收藏等条件筛选商品。
3. 将当前筛选结果一次性报名到用户已勾选并保存的官方/店铺活动。

## 使用方式
1. 先在 Search CPO 页面选择默认官方活动和店铺活动，并点击“保存默认活动”。
2. 点击“刷新 CPO 商品”，让系统从 Seller 页面同步当前 CPO 商品列表。
3. 在页面上按需要筛选商品。
4. 点击“报名当前筛选结果”，系统会把当前筛出的 `source_sku` 批量提交到已保存活动。

## 边界说明
1. 这条链路处理的是“当前筛选结果”，不是固定只处理 `state1`。
2. 如果运营只想处理 `state1` 商品，应先在页面上把规则状态筛成 `State 1` 再执行。
3. 这条链路不负责等待 `state2`、不负责退出其它活动、也不负责 `enable` 或加入 `Morkovsk`。
4. 人工批量报名和状态迁移自动化共用同一份“默认活动”配置，但它们是两条独立执行链路。
